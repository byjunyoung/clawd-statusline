# 버린 것들

이 플러그인은 상태줄 하나다. 그 자리에 오기까지 네 가지를 만들어 보고 뺐다.
**여기 적어두는 이유는 하나다. 나중에 누가 그중 하나를 다시 떠올릴 것이기 때문이다.**

작성 2026-09-04.

## 출발점

앤트로픽이 2026-04-01에 낸 `/buddy`. 계정 해시로 종과 스탯을 뽑아주는 터미널 다마고치였고
2026-04-09 v2.1.97에서 조용히 사라졌다. 복원 요청 이슈는 `not planned`로 닫혔다.
버디가 안 한 것이 둘이다. **자라지 않았고**, 사용 방식과 **아무 상관이 없었다.**
그 둘을 채우려는 시도가 아래 넷이다.

## 1. Clawd 옆에 세울 새 생물 — 세 번 그렸고 세 번 다 실패

앞을 보는 둥근 덩어리에 눈 두 개면 무엇을 붙여도 작은 Clawd로 읽힌다. 꼬리를 달아도,
목을 잘록하게 해도, 옆모습 네발로 종을 바꿔도 "짭 Clawd"라는 인상이 안 없어졌다.

원인은 단순했다. **Clawd의 친구를 그리면 그건 Clawd다.**

## 2. 악세사리 — 캔버스가 천장이었다

레벨로 모자를, 칭호로 따라다니는 친구를 여는 옷장을 만들어 실제로 돌려봤다.
색을 몸통과 다르게 칠해야 혹이 아니라 걸친 것으로 읽힌다는 것까지 알아냈고 그건 맞았다.

그래도 뺐다. Lv.36에서 37로 가도 아무 일이 없고 다음 모자는 40이다. 65레벨에 7개면
보상이 너무 드물다. 촘촘하게 고쳐도 9칸 스프라이트에 얹을 수 있는 건 머리 위 색덩어리뿐이라
천장이 안 올라간다.

**캔버스가 못 받쳐주는 보상 체계는 밀도를 늘려도 안 산다.**

## 3. 원본에 없던 것 — 표정, 그리고 자세

잔량에 따라 입을 벌리고 눈을 감는 포즈 다섯(`blink` `wary` `wary-up` `alarmed` `panic`)을
새로 그려 쓰고 있었다. 앤트로픽 원본은 `default` `look-left` `look-right` `arms-up` 넷뿐이고
전부 입이 없다.

넷만 남기고, 얼마나 다급한지는 **어느 포즈를 얼마나 자주 뽑느냐**로만 말하게 바꿨다.
그림은 하나도 안 늘었는데 두리번거리는 빈도와 팔을 드는 비율이 올라간다.
`tests/test_poses.py`가 이걸 지킨다 — 포즈가 넷을 넘거나 몸통 줄에 틈이 생기면 실패한다.
README에 넣을 포즈 그림도 `tools/render_poses.py`가 코드에서 읽어 그린다. 손으로 그렸더니
지운 포즈 넷을 README가 계속 "new"라고 광고하고 있었다.

**그런데 포즈 넷을 지키는 것만으로는 모자랐다.** 중단 반응을 만들면서 `arms-up`을 한 줄
내린 프레임을 썼다. 그림은 원본 것인데 그 자세로는 원본이 한 번도 안 세운다. 실제로 원본
바이너리(2.1.260 `chunk-j9b3a0wh.js`)를 열어보니 여섯 시퀀스를 통틀어 나오는
(포즈, 세로오프셋) 짝은 다섯뿐이고, **offset 1은 `default`에만 붙는다.**

```
default/0   look-left/0   look-right/0   arms-up/0   default/1
```

유휴 반응도 같은 이유로 고쳤다. 웅크린 자세를 계속 유지해 "앉음"으로 쓰고 있었는데,
웅크리면 몸통 줄 양 끝 한 칸(`▝`와 `▀`)이 잘린다. **원본의 먼지 `·`/`~`는 장식이 아니라
그 잘린 두 칸을 메우는 것이다.** 먼지 없이 오래 웅크리고 있으면 9칸이던 몸이 7칸으로
쪼그라들어 보인다. 원본도 celebrate 꼬리에서 같은 모양이 되지만 180ms라 안 보인다.

지금은 유휴일 때 원본이 쉴 때 도는 순서(`default`×12 → `look-right`×5 → `look-left`×5)를
그대로 돌린다. 가라앉았다는 표시가 자세가 아니라 **규칙성**이 됐다.

`tests/test_poses.py`의 `OFFICIAL_FRAMES`가 이걸 지킨다. 저 다섯 밖의 짝이 나오거나
웅크리지 않았는데 먼지가 뜨면 실패한다.

## 4. 카드 — 만들 수는 있는데 남들이 이미 한다

`/clawd-statusline:card`. 자기 대화 기록 90일치를 훑어 레벨과 스탯 다섯을 보여줬다.

```
  Clawd  Lv.36
   ▐▛███▛█    FED    245.0M      APPETITE  ████████░░   75
  ▝▜██████▀   NEXT   8.3M        REACH     ████████░░   76
    ▝▝ ▝▝     AGE    177 days    STAMINA   ███████░░░   68
```

동작은 했다. 뺀 이유는 만듦새가 아니라 시장이다. 사용량 대시보드는 이미 빽빽하고,
그중 [claude-usage-analytics](https://github.com/ae-reid-havens/claude-usage-analytics)는
"personality insights, achievement badges"를 그대로 판다.
[cc-proficiency](https://github.com/Z-M-Huang/cc-proficiency)는 53개 규칙으로 숙련도 배지를
SVG로 뽑는다. **장부까지 드는 마스코트는 마스코트로도 대시보드로도 어중간하다.**

빼면서 훅이 통째로 없어졌다. 설치할 게 없다는 것이 지금 이 플러그인의 성격이 됐다.

설계값을 남겨둔다. 다시 만들 일이 있으면 여기서 시작하면 된다.

| 항목 | 값 |
|---|---|
| 먹이 | 출력 + 새 입력 + 캐시 쓰기. **캐시 재읽기는 뺀다** — 실측 120억이라 넣으면 다 묻힌다 |
| 레벨 곡선 | `C(n) = 5,000 × n³ × 요금제계수` |
| 요금제계수 | Pro 0.45 / Max 5x 1.0 / Max 20x 2.0 (소비 여력 비의 제곱근 = 절반 보정) |
| 스탯 | APPETITE 활동일당 먹이 · REACH 바깥 도구 비중 · STAMINA 세션당 턴+컴팩트 · PACK sidechain · NOCTURNE 22–06시 |
| 칭호 | 90 넘으면 GLUTTON · ROAMER · MARATHON · LEGION · OWL |
| 나이 | 부화가 아니라 `claudeCodeFirstTokenDate`부터 — 설치가 늦었다고 손해 안 본다 |

한 번의 API 호출이 파일에 여러 줄로 저장되므로 `message.id`로 묶어야 한 번만 세어진다.
실측에서 4,190줄이 2,394번의 호출이었다.

**설계 단계에서 APPETITE를 92로 봤는데 실제로는 75였다.** 활동일당 먹이를 중앙값으로 잡으니
가볍게 쓴 날이 값을 끌어내린다. 기준점을 억지로 맞추지 않고 그대로 뒀다.

코드는 `git log`에 남아 있다. **`0.4.0` 태그가 카드가 살아 있던 마지막 판이다.**
